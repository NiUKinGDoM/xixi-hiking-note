# 真机回归清单（发版前必走一遍）

> 为什么要有这份清单：自动化门禁 79 项永远全绿，但 **v1.0.7.7 的左右滑动（HorizontalPager）
> 让整页按钮全部点不动**，测试完全没发现 —— 因为 `performTouchInput { click() }` 是
> **零位移的"完美点击"**，而真机手指按下必然抖几像素，正好被 Pager 的拖动判定拿走。
>
> 结论：**涉及手势、生命周期、GPU 渲染的问题，只能靠真机走一遍。**
> 每次打包后装上，按下面 10 条过一遍，5 分钟。

---

## 一、点击是否通（最高优先级）

**1. 四页各点一个按钮**
- 概览：点「我的里程碑」→ 里程碑弹窗出现
- 记录：点右上「＋」→ 编辑表单出现
- 计划：点右上「＋」→ 新建计划出现
- 设置：点「导入数据」→ 导入弹窗出现

> 期望：点一下就出，不需要点第二下。
> 失败典型：无反应 / 闪一下就没 / 只出个 toast「操作出错了」。

**2. 设置页六个入口逐个点**
导入数据、导出数据、照片占用、隐私政策、免责声明、支持作者、更新日志

> 这 7 个是本轮出过事的地方，必点。

## 二、手势

**3. 左右滑动切页**
从记录页向左滑 → 到设置页；再向右滑 → 回记录页。

> 期望：滑一下切一页；**切页后按钮仍然点得动**（这是 Pager 时代的坑）。
> 另测：轻轻点一下不动，不应该切页。

**4. 页面内滚动 + 点击**
记录页往下滚两屏，再点一条记录。

> 期望：直接打开详情。失败典型：第一下只是停止滚动、要再点一次。

**5. 底栏**
- 点「记录」→ 切到记录页，图标和胶囊一起弹一下
- 已在记录页时再点「记录」→ 平滑回到顶部 + 分页回第 1 页
- 山册视图下再点「记录」→ 收起所有山卡抽屉并回到顶部

## 三、弹窗

**6. 弹窗能开、能关、能滚**
任选三个弹窗（记录详情 / 隐私政策 / 更新日志）：
- 打开后底部有「关闭」（或取消/保存）
- 长内容能滚动，按钮不被裁掉
- 点弹窗外的空白 → 关闭
- 返回键 → 关闭（不是退出 App）

**7. 弹窗不叠**
记录详情 → 点删除 → 确认框弹出（详情应让位）→ 取消 → **详情要回来**。

> 这是 v1.0.7.4 的致命 bug：先开的弹窗被压住后永久隐身。

## 四、核心流程

**8. 写一条记录**
记录页「＋」→ 填山名 / 日期 / 海拔 / 难度 → 保存 → 列表出现 → 点开看详情 → 编辑 → 删除（要二次确认）。

**9. 灯箱**
记录详情 → 点照片：
- 打开后标题在左上、页码在正中、✕ 在右上
- 左右滑翻页（1× 时）
- 双指放大后横拖 **不翻页**
- 点照片本身 **不关闭**
- 「保存」→ 相册里能找到

**10. 备份往返**
- 设置 → 导出数据 → 导出完整备份（.zip）→ 保存到手机
- 设置 → 导入数据 → 选那个 zip → 提示导入结果，记录数量和照片数量对得上
- 设置 → 照片占用 → 数字与记录里的照片张数一致

**11. 再按一次退出**
在记录页按返回键：第一下只弹 toast「再按一次退出」，页面不动；2 秒内再按一下才退出。

> 期望：不会一按返回就退 App。弹窗打开时按返回，应该关弹窗（不是退 App、也不是这条 toast）。

## 附加：只在特定条件下才出现的，顺手看一眼

| 触发条件 | 期望 |
|---|---|
| 全新安装（无记录） | 概览出现欢迎卡；记录/计划页出现引导卡；先弹法务确认 |
| 记录 ≥ 11 条 | 记录页出现分页条，上一页/下一页箭头居中可点 |
| 记录 ≥ 2 座同名的山（如「太白山」和「太白山拔仙台」） | 山册 → 打开一张卡 →「连接到另一座山」→ 勾选 + 改名 → 卡片名字变了 |
| 距离上次备份 > 30 天 | 概览出现备份提醒卡 |
| 系统深色模式 | 四页 + 弹窗都跟着变深；弹窗边界仍能看清 |
| 系统字体调大 | 文字不溢出、按钮不被挤掉 |

## 记录方式

发现问题的格式（照这个写，我能直接定位）：

```
【序号】哪一页 → 点了什么 → 期望什么 → 实际什么
例：【1】设置页 → 点「导入数据」→ 应该弹导入窗 → 完全没反应
```

如果出现「操作出错了：xxx」的 toast，把冒号后面的内容抄下来 —— 那是被拦住的异常消息。

**① 热力图的年月选择器**
概览页 → 徒步足迹卡右上角的年月 → 弹窗里点「2025」→ **弹窗不能关**（月份格要跟着换成 2025 有记录的月份）→ 再点「8 月」→ 这时才关，卡片切到 2025-08。

**③ 完整备份里的回忆册**
设置 → 导出完整备份压缩包 → 解压 zip → 打开 `回忆册.html`：
标题、日期大字、难度五档圆点、小日记、照片墙都要在；照片应能直接显示（相对路径 `photos/<id>.jpg`）。
失败典型：zip 里没有这个文件；HTML 空白；照片不显示。

## 2026-11-05 新增：工具链与三条必测

### 日常节奏（不用等发版）

改完代码先跑 **`bash tools/doctor.sh`**（10 秒，不编译）：
崩溃点 / 代码气味 / 设计一致性 / 版本文档 / 系统审计 / 上次单测结果，
一项一条，红了再改。发版前才跑 `bash tools/gate.sh`（编译 + 106 项测试 + Lint）。

真机不对劲时跑 **`python tools/logcat.py --wait 20`**（先清空再复现），
它会自动分出 FATAL / ANR / SOFT / GLASS 四类。没抛异常的话，
用 App 内「设置 → 诊断报告」，里面有最近 20 步操作轨迹。

### 必测三条

**① 分享卡（Android 7~9 的真崩溃，只在旧机上复现）**
点任意记录 → 分享 → 卡片要能出来，不能闪退。
这一版修的是 `LinearGradient` 走了 API 29 的重载；新手机测不出来，别跳过。

**② 跨月改日期**
编辑计划 → 选 1 月 31 日 → 把月份切到 2 月 → 日期应自动落到 28/29 日，
弹窗不闪、不重复弹。

**③ 引导卡自动收起**
清空数据后首次进入记录页，引导卡出现；导入一条记录后，引导卡应自己消失
（这一版把它从「组合期写 state」改成了 LaunchedEffect，晚一帧收起）。

## 2026-11-05 新增必测：照片删除（两条）

**① 灯箱两段式删除**
编辑一条有照片的记录 → 点照片进灯箱 → 点底部「删除」：
按钮应立刻变成「确认删除？**且照片还在**」→ 再点一次才真的消失。
另外两条复原路径都要试：点完后**等 3 秒不点**（应变回「删除」）、或者**翻到下一张**（应变回「删除」）。
失败典型：第一下就删了（等于没有确认）；或者点完变红但永不复原（下次手滑就直接删）。

**② 缩略图上不该有删除按钮**
编辑记录页的照片列表，缩略图右上角**不应该**再有那个小「×」。
删除统一在灯箱里做 —— 不再有第二个入口、也不用记哪个入口有确认。

判据：**一次误触不能丢东西**。

## 2026-11-11 新增必测（v1.1.0.6 ~ v1.1.1.x 这批功能）

### ⏰ 计划提醒（最容易「看着像好了」的一条）
1. 新建计划，日期设成**明天**
2. 从最近任务里**彻底划掉** App（不是切后台）
3. 明早 8 点看有没有通知 —— 这是唯一能证明闹钟真的排上了的方法
4. 测完再重启手机，等下一次计划日期，确认开机重排也生效（BootReceiver）

> 失败特征：能收到通知但只有打开 App 时才有 → 说明只是 dailyReminders 生效，闹钟没排上。

### 🖼 年度回顾存图
- 年度回顾 → 标题栏右侧「存图」→ 相册打开看三件事：
  - 背景**不是透明的**（透明 = 底色合成失败）
  - 6 个指标数字完整，没被切边
  - 深色模式下背景应是深蓝 ，不是白

### ⬇️ 更新断点续传
- 有新版本时点更新，下到一半开飞行模式
- 关掉飞行模式再点 → 进度应从断点继续，**不是从 0% 重来**

### ☁️ 云同步冲突保护
- 两台设备（或网页版 + App）都改数据后再同步
- 后同步的那台应提示「云端有更新的备份」，而不是静默覆盖掉对方

### 🏔 山名联想 / 单山对比
- 新建记录 → 山名输入框下方应出现去过的山，点一下填入
- 同一座山记两条 → 第二条详情应显示「第 2 次来这座山 · 上次 X · 这次快/慢 Y」

### 📷 照片 EXIF 填日期
- 新建记录 → 选一张**相机拍的照片**（不是截图）→ 日期自动变成拍摄时间
- 选截图（无 EXIF）→ 日期保持不动；编辑老记录时也**不该**被覆盖
