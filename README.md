## 📥 下载

**[最新版本 · GitHub Releases](https://github.com/NiUKinGDoM/xixi-hiking-note/releases)**

装好之后不用再回来找包 —— 在 App 里「设置 → 检测更新」就能直接升级：
应用内下载 → 校验签名 → 拉起系统安装器。

> 🛡️ 所有正式版同一个签名，覆盖安装不会丢数据。
> 下载的包会先比对签名证书指纹，对不上直接丢弃（防的是"更新源被换掉"）。

## ✨ 能做什么

| 板块 | 能力 |
|---|---|
| 概览 | 次数 / 里程 / 用时 / 最高海拔、年度足迹热力图、年度回顾（含"和去年比"） |
| 记录 | 增删改、难度 1-5、小日记、心情 / 天气 / 同行人、每条最多 24 张照片、列表与山册双视图 |
| 计划 | 列表 + 日历双视图、过期 / 今天 / 明天三态、到期「完成 / 延期」、完成自动转记录、提醒 |
| 搜索 | 山名、日记、心情、同行人全文搜索 |
| 分享 | 一键生成分享卡 |
| 设置 | WebDAV 云备份（自动留 2 份）、备份导入导出、深色模式、检测更新、完整更新日志 |

## 🔒 隐私

- 记录与照片**只存本机**：没有账号、没有统计 SDK、没有广告
- 联网只有三件事：查新版本（GitHub）、你自己配置的 WebDAV、你主动导出的诊断信息
- **没有开发者服务器**，所以数据也无处上传
- 完整说明在 App 内「设置 → 关于应用 → 隐私政策」

## 🧱 技术

- Kotlin + Jetpack Compose，**不是 WebView 套壳**
- Room 本地数据库，3 个版本迁移全部有覆盖（老用户升级不会清库）
- 液态玻璃视觉：`Kyant0/backdrop`
- 最低 Android 7.0（API 24），target 36

## 🛠 开发与发版

构建步骤见 [构建说明-ANDROID.md](构建说明-ANDROID.md)；工程细节（玻璃参数、踩过的坑、工具链）在 [docs/](docs/)。

```bash
python tools/bump.py --note "这次改了什么"    # 升版本 + 写更新日志
bash   tools/gate.sh                        # 门禁（编译/lint/全量测试/静态扫描）
python tools/release.py                     # 出包 + 拷到桌面
python tools/ghrelease.py --tag vX.Y.Z --apk 包路径
```

门禁不是走过场：崩溃点扫描、代码气味、删除入口二次确认、数据库迁移覆盖、签名指纹校验
都在里面，任何一项红了就不许发。

## 版本号

四段 `1.x.x.x`，唯一输入是 `versionCode`：

```
索引   = vc - 1
第二段 = (索引 / 121) % 11
第三段 = (索引 / 11) % 11
第四段 = 索引 % 11
```

每段 0~10，满 10 进位。已写进 `app/build.gradle.kts`，**只改 `val vc = N` 这一行**，
`versionName` 自动算出来。
