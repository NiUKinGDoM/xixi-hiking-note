# 🏔️ 徒步小记

一款由 XiXi 亲手制作的徒步日记软件：记录每一次徒步与登山的足迹、照片与感想，统计里程难度，规划下一次出发。

**Made by xixi 💛**

> 💡 这个项目从 **2025 年 12 月 5 日** 的一次灵光开始。在那之前，它作为雏形已经迭代过**203版**；然后网页版（浏览器 / PWA 都能用）迭代了**316版**，后来用 Kotlin + Compose 重写了 Android 端 —— 也就是这个仓库，目前已迭代**135版**。
> 两端共用同一套数据协议，备份可以互相导入。

> 📌 当前版本以 [GitHub Releases](https://github.com/NiUKinGDoM/xixi-hiking-note/releases) 为准，每个版本都有完整的更新说明。

## 🔒 隐私承诺

- 记录与照片**只存本机**：没有账号、没有统计 SDK、没有广告
- 联网只有三件事：① 查新版本（版本清单走 jsDelivr CDN、安装包走镜像或 GitHub，均在**中国境外**，不想跨境可离线使用）；
  ② 你自己配置的 **WebDAV**（数据同步到**你自己的**网盘，服务器在中国境内）；
  ③ 崩溃诊断只在本机生成，**不会自动上传**，只有你主动导出并发送时我们才看得到
- **没有开发者服务器**，所以数据也无处上传
- 完整说明见 App 内「设置 → 关于应用 → 隐私政策」

## 🧱 技术

- Kotlin + **Jetpack Compose**，不是 WebView 套壳
- **Room** 本地数据库，3 个版本迁移全部覆盖（老用户升级不会清库）
- 液态玻璃视觉：[Kyant0/backdrop](https://github.com/Kyant0/AndroidLiquidGlass)
- 最低 Android 7.0（API 24），target 36
- 包体约 6.5MB（其中中文字库占 6.7MB，**这是全站宋体正文字形的代价**，不是浪费）

## 🛠 开发与发版

构建步骤见 [构建说明-ANDROID.md](构建说明-ANDROID.md)；工程细节（玻璃参数、踩过的坑、工具链）在 [docs/](docs/)。

```bash
python tools/bump.py --note "这次改了什么"    # 升版本 + 写内置更新日志
bash   tools/gate.sh                        # 门禁（编译 / lint / 全量测试 / 静态扫描）
python tools/release.py                     # 出包 + 自动上传 Release + 更新 version.json
```

门禁不是走过场，目前 **140 项测试 + 8 个静态扫描**：

| 扫描 | 挡住什么 |
|---|---|
| `crashscan` | 会用不可控数据抛异常的写法（`!!` / 下标 / 字符串直转数字 / 日期解析） |
| `smellscan` | 代码气味（全局作用域、静默吞异常等） |
| `delguard` | 删除入口没有二次确认 |
| `overlayscan` | 内层弹窗盖不住外层 |
| `migrateguard` | 数据库迁移没写 |
| `signpin` | 签名指纹漂移 |
| `sizeguard` | **单文件超过 1500 行**（防止拆开的代码又堆回去） |
| `designcheck` | emoji / 字号 / 弹窗档位不一致 |

任何一项红了就不许发。

发布顺序（脚本已内置）：
`bump` → `gate` → `assembleRelease` → `apkcheck/signpin/obfcheck` → `upload` → `promote` → **写 version.json + 刷新 jsDelivr 缓存 + push**

> ★ 上传用的资产名是 **`tuxiaoji-vX.Y.Z.apk`（纯 ASCII）**。
> GitHub 会把中文资产名里的中文字符剥掉，而 App 靠资产名识别安装包 —— 名字一坏，
> 用户永远收不到更新且不报错。详见 `tools/ghrelease.py`。

### 检查更新的链路（2026-11 重构）

```
App ──① jsDelivr 上的 version.json（国内直连 ~0.25s）── 有新版？
        └─② 拿不到 → 退回 GitHub API（境外，常常连不上，只作兜底）
下载 ──③ gh-proxy 镜像 → gh.xmly 镜像 → 官方直链（支持断点续传）
```

**为什么不用 GitHub API 当主源**：国内直连 `api.github.com` 基本不通（实测 1 毫秒断连）。
`version.json` 是仓库根的一个 1KB 静态文件，由 `release.py` 自动改写 + 主动 purge 缓存。

## 版本号

四段 `1.x.x.x`，唯一输入是 `versionCode`：

```
索引   = vc - 1
第二段 = (索引 / 121) % 11
第三段 = (索引 / 11) % 11
第四段 = 索引 % 11
```

每段 0~10，满 10 进位。已写进 `app/build.gradle.kts`，**只改 `val vc = N` 这一行**，
`versionName` 自动算出来。
